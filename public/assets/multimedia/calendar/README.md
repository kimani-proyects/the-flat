# Calendar Photos

Pega aquí 12 imágenes JPG con nombres `01.jpg` ... `12.jpg`
(uno por mes — Enero=01, Diciembre=12).

Tamaño recomendado: 480×220 px (proporción ~2.18:1).
Formato: .png o .jpg (renombra extensión a .jpg para que cargue).

Si falta algún mes, el calendario sólo mostrará el color sin foto.
